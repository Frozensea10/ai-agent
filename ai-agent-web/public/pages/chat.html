如何配置 MCP 工具？

配置 MCP 工具需要以下步骤：

  1. 在 MCP 工具页面点击"添加工具"
  2. 填写工具名称、描述和端点地址
  3. 配置认证参数（API Key 或 OAuth）
  4. 测试连接并保存配置
